用安卓手机继续 Windows 电脑上的同一段 Codex 聊天：查看回复、发送指令、切换聊天，使用桌面实际提供的菜单和问答控件。

## 手机查看电脑生成的文件

0.4.0 会将助手回复中的本地文件链接显示为文件卡片。点击后下载并弹出安卓“选择应用打开”，单文件上限 100 MB；需安装相应阅读器。支持进度、取消、文件大小和 SHA-256 校验。

[查看详细操作、更新方法与故障处理](docs/手机打开电脑文件.md)。本次新增功能的真实手机与当前桌面端到端验收待完成。

## 六步开始

1. 从 [Codex 官方页面](https://openai.com/codex/) 安装 Windows 桌面应用，登录自己的账号，确认桌面可以正常聊天。
2. 手机、电脑从 [Tailscale 官网](https://tailscale.com/download) 安装并连接同一私有网络。
3. 下载并完全解压完整包，将 **02-Windows电脑端** 整体放在电脑固定位置，不能只复制启动器。
4. 等 Codex 当前任务结束并处理草稿，正常退出应用，再双击配套的 **启动 Codex Pocket.cmd**。
5. 安卓安装 APK，打开 Codex Pocket，扫描自己电脑设置页的二维码并确认连接。
6. 核对两端聊天标题，手机和电脑各发送一条测试文字，完成同一聊天真实收发检查。

以后保持两端 Tailscale 在线，电脑唤醒、联网、登录且未锁屏，Codex 保持运行。手机可使用 Wi-Fi 或移动数据，配对成功后不必每次扫码。

## 功能

- 同步当前桌面聊天、流式文字、Markdown、代码块与图片；侧栏显示项目分组、已同步聊天搜索和新建聊天。
- 同步输入框“＋”、聊天“⋯”及子菜单；计划模式、目标、权限、模型、思考强度以桌面实际选项为准。
- 执行中进入队列时显示消息条、预览、引导、删除和条目菜单；发送方式跟随桌面当前控件。
- 支持真实问答卡片、选项、自定义答案及现有审批与权限确认。
- 手机文件、电脑目录选文件、手机画板、图片预览和双指缩放；附件需明确加入聊天后手动发送。单文件最大 20 MB，目录需展开后选文件。
- 电脑草稿保护、按聊天保留手机草稿、回执防重复、断线重连且不自动补发；停止任务需二次确认。

## 0.4.0 修复

- 修复关闭手机“＋”后电脑菜单残留、后续手机操作无响应；手机立即收起菜单，关闭回执与发送等待分离。
- 通过已展开的实际入口关闭菜单，不发送可能停止任务的 Esc；无法关闭的浮层使用短超时。
- 支持将桌面队列“编辑消息”产生的自有草稿移到手机编辑，保护两端已有草稿。

## 连接与数据

桌面调试入口仅监听 `127.0.0.1:9222`；配套 HTTPS/WebSocket 只监听电脑 Tailscale 地址的 43827 端口，本机管理页为 `127.0.0.1:43828`。无需路由器公网映射，不公开 CDP。

首次运行在自己的电脑端目录生成 `data`，保存证书、授权、回执和附件。不要分享运行后的 data、二维码、配对内容或完整管理页地址。分享应使用干净 Release 包。

手机固定校验电脑证书，凭据由 Android Keystore 保护；接口只接受已实现的聊天操作，不接受任意脚本、选择器或系统命令。附件磁盘副本会保留供桌面后续读取，聊天不再引用时再清理。

## 源码与构建

- `android/`：Kotlin + Jetpack Compose 客户端。
- `companion/src/`、`companion/test/`：Node.js + TypeScript 配套程序及测试。
- `scripts/`：Android 构建和便携包打包脚本。
- `docs/`：安装、使用、排错和构建教程。

电脑端用 Node.js 24，执行 `npm ci`、`npm run build`、`npm test`。安卓用 JDK 17、SDK 35、Gradle 8.13；详细前提见 [源码与构建说明](docs/03-源码与开发资料/源码与构建说明.md)。
