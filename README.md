# Codex Pocket 0.4.3

用安卓手机继续 Windows 电脑上同一段 Codex 聊天。非官方个人工具，支持 Windows x64、Android 8.0 及以上，两端需连接自己的 Tailscale 私有网络。

## 首次使用

1. 电脑安装并登录官方 Codex，确认可以正常使用。
2. 电脑与安卓手机安装 Tailscale，连接同一私有网络。
3. 完全解压完整包，将 02-Windows电脑端 整体放到固定目录。等 Codex 当前任务结束、处理草稿并正常退出后，双击“启动 Codex Pocket.cmd”。
4. 手机安装 APK，扫描自己电脑设置页二维码，核对聊天标题，按教程完成一次真实收发。以后无需重新配对。

电脑需保持唤醒、联网、登录且未锁屏。日常运行无需 Node、JDK 或 Android SDK。分享包不含官方 Codex／Tailscale 安装器、账号、私人证书、聊天及配对数据。

## 功能

同步聊天与历史、Markdown、代码、图片、问答与审批；项目列表和工作目录选择；桌面“＋／⋯”菜单、计划、权限、模型与思考强度；执行中的排队、引导和停止。支持手机文件、电脑选文件和画板，上传每文件 20 MB；[助手生成文件下载并选择应用打开](docs/手机打开电脑文件.md)，每文件 100 MB。已有电脑草稿受保护，断线不会自动重发指令。

## 0.4.3 发送、附件、项目和工作目录升级（2026-10-21）

- 修复手机输入文字后发送按钮不可点：桌面空输入框可能禁用 Send，执行中可能只显示 Stop。手机现在允许提交草稿，电脑插入后仍核对实际启用的发送／排队按钮，不会把停止按钮当发送按钮。
- 修复“＋ → Files and folders”等英文菜单没有弹出手机文件选择的问题。点击文件入口后选择“从手机选择”，会打开安卓系统文件选择器；也保留“从电脑选择”和图片预览。上传后先点击“加入聊天”，再发送。
- 修复消息归入正式轮次时旧缓存保留副本：消息身份独立于可变轮次；虚拟副本合并，同文字不同消息保留。多题问答按实际题目索引区分，避免共用调用标识导致漏题。部署重启清理旧内存缓存，按“加载更早的消息”重新读取历史。
- 打开聊天侧栏或新建页时，通过桌面实际 Show more 和展开控件加载项目与聊天；无需先在电脑点 Show more。保留“加载更多项目和聊天”按钮。搜索范围仍为已同步聊天，单次展开有数量与时间上限。
- 新建页保留普通本地聊天、已有项目，并新增“选择电脑工作文件夹”：磁盘 → 文件夹 → 使用此文件夹 → 在电脑打开新聊天。目录使用短期有效的标识，手机不能提交任意路径或脚本。首次新增目录可能出现“Trust this folder?”；由用户在手机确认或取消，确认后加载项目列表并选择新项目打开聊天。不会自动信任目录、自动重试创建或发送首条消息。

### 升级

手机覆盖安装 Codex-Pocket-0.4.3.apk，选择“更新”，不要卸载。电脑升级到 0.4.3，仅重启配套程序，保留原 data；本机已部署，原证书与授权未变，Codex 未重启。新用户下载 Full-Package.zip，先打开 00-完整安装与使用教程.html。
