- Codex Pocket：本包的非官方个人工具，含已签名安卓 APK、Windows 配套程序与源码。
- Codex 桌面：接收者自行从 https://openai.com/codex/ 进入官方 Windows 下载入口并登录自己的账号；本包不含官方安装器、账号或订阅。
- Tailscale：两端自行从 https://tailscale.com/download 安装，使用自己的私有网络。Windows 可用官网安装器，安卓按官方页面选择 Google Play/其提供的下载渠道。若不能访问，不要随意使用来路不明的 APK。

- 安卓主要组件包括 Kotlin、Jetpack Compose/AndroidX、OkHttp、协程、ZXing、Markwon 等；精确版本见源码 android/app/build.gradle.kts，遵循各组件原有许可证。
