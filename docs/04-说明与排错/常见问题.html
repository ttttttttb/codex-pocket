常见问题与处理

先确认：两端 Tailscale 在线，电脑未休眠、未锁屏，Codex 和配套程序运行；只保留一个 Codex 聊天窗口。

现象按顺序处理
启动器提示未找到 Codex先安装并登录官方 Windows 桌面应用。当前启动器识别 OpenAI.Codex 商店包；其他安装方式不保证自动识别。
浏览器没出现设置页在固定安装目录重新运行“启动 Codex Pocket.cmd”。查看同目录 data/startup-error.log 的错误；不要发送 dashboard.url、tls.json 或 device.json。
已配对，尚未连接 Codex常见原因是 Codex 已经从普通快捷方式启动。先等任务结束并处理草稿，正常退出整个 Codex，再运行配套启动器；点设置页“重新检测”。
设置页显示没检测到 Tailscale打开 Windows Tailscale，确认已登录且连接，随后点“重新检测”；确认手机使用同一私有网络。
扫码失败或配对码过期电脑点“刷新二维码”，手机重新扫；二维码五分钟有效。相机拒绝授权时可使用“无法扫码？粘贴配对内容”。
提示已有手机配对默认单电脑、单手机。在电脑设置页“撤销手机授权”后给需要使用的手机重新扫码；不要向对方索要发送者的配对文件。
手机显示证书不匹配不要跳过校验。先确认自己连接的是正确电脑；电脑地址/证书改变后，在正确电脑撤销旧授权，手机解除配对再扫新码。解除配对会清除手机草稿。
手机只在家里 Wi-Fi 可用手机和电脑都需 Tailscale 持续连接。切换移动数据后检查 Tailscale 是否仍显示已连接；允许它使用移动数据和必要的后台网络权限。无需路由器端口映射。
两个手机 VPN 不能同时启用Android 通常一次只允许一个 VPN 服务。Tailscale 要处于实际连接状态；其他 VPN/代理应用可能冲突，按自己的网络环境处理。
手机无响应/操作结果待确认先收起菜单，检查原指令是否已经执行；确认后点“我已检查聊天”。不要反复发送。可在“连接与外观”手动重连。
关闭＋后再次卡住先确认手机和电脑端均为 0.4.3，不能只更新 APK；重连后测试。0.4.3 已修复独立菜单关闭逻辑。仍复现时记录时间、操作步骤及状态文字。
提示电脑有未发送草稿为避免覆盖，手机发送/新建/切换/附件等会被阻止。先在电脑自行发送、保存或删除草稿。
找不到全部历史聊天或旧图片侧栏搜索仅覆盖已同步的聊天。历史/图片依赖桌面已加载的内容，先打开相应聊天并加载历史，再重试图片。
部分菜单选项不存在/禁用以当前桌面的真实控件为准，账号、项目、执行状态及桌面版本会影响可用项；不要强行点击。窗口/侧边面板专属操作不在手机显示。
重复出现文字相同的消息一次真实发送应只有一条；主动发送两次同样文字会保留两条。先对照电脑原聊天，不按文字盲目删除。
文件上传失败单文件需 1 字节至 20 MB，待添加缓存总计 64 MB、30 分钟过期；确认仍在原聊天，重新选择。目录需展开后选文件。
文件已选择却没发出先预览并点“加入聊天”，确认成为桌面附件，再手动发送；选文件/绘图不会自动发消息。
电脑任务意外停止0.4.3 不用 Esc 清理菜单，停止按钮需二次确认。记录时间和最后点击的控件，核对桌面报错/网络/休眠；不能把所有中断都归因于同一个问题。
新版 APK 提示无法更新检查是否确为相同应用 ID 和签名的后续版本。不要随意卸载；卸载会删除本机配对/草稿。自行重签名的 APK 通常不能覆盖本包。
电脑端无法重新连接等待当前操作结果确认后，可用“修复电脑端连接.cmd”只重启配套程序；它不会修复一个未经调试启动的 Codex，后者仍需任务结束后正常重开。
端口被其他程序占用保留提示文字，检查本机 43828、Tailscale 地址 43827 和本机 9222 是否被占用；不要结束不认识的进程或把调试端口开放到公网。

防火墙：如果 Windows 询问是否允许包内 runtime/node.exe 联网，只允许自己使用的受信网络。网络被策略限制时，需允许手机 Tailscale 地址访问电脑 Tailscale 地址的 TCP 43827；不要关闭整个防火墙，不要开放公网或 9222。工作/学校电脑须按其管理规则处理。

提交故障时提供：Windows 版本、Codex 版本、手机型号/安卓版本、App 版本、网络类型、时间、操作步骤、经过遮挡的错误截图。不要提供二维码、手动配对内容、完整管理页地址、凭据、私钥或完整聊天记录。
