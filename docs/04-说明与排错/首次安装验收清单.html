首次安装验收清单

这是接收者需自己完成的检查表，不代表本包已在其设备上通过。

  • ☐ 电脑 Codex 可正常聊天；Tailscale 两端属于同一私有网络。
  • ☐ 电脑设置页显示已连接，手机显示正确电脑和聊天标题。
  • ☐ 手机发一条唯一测试文字，两端各只显示一次；助手回复持续更新。
  • ☐ 电脑发一条消息，手机收到；主动两次发送相同文字仍显示两条。
  • ☐ 电脑切换聊天，手机跟随；手机侧栏选择聊天，桌面也打开同一条。
  • ☐ 新建聊天选择已有项目/普通本地聊天，首条消息后对应正确聊天。
  • ☐ ＋菜单打开后在手机关闭，电脑菜单也退出；连续三轮后仍可操作。
  • ☐ 聊天⋯、权限、模型、思考强度和计划模式按桌面真实选项同步。
  • ☐ 电脑已有草稿时，手机不会覆盖；两端草稿都保留。
  • ☐ 执行中发送进入实际队列时出现消息条；预览、引导、删除和条目菜单身份正确。
  • ☐ Codex 出现真实问答时，手机可选择选项/自定义答案并提交；已失效问题不再提交。
  • ☐ 手机照片、电脑文件、绘图可先预览并加入聊天；图片可放大、缩放、移除。
  • ☐ 停止操作先要求确认；打开/关闭菜单不会停止任务。
  • ☐ Wi-Fi 切移动数据后能重连；短断网恢复后没有重复执行或发送到错误聊天。
  • ☐ 发送后立即断网时，能先确认原结果，不会自动补发；电脑睡眠唤醒后重新连接。
  • ☐ 测试时若确需撤销授权，撤销后手机无法操作；重新扫码后恢复。

建议测试消息：“连接测试-自选唯一编号：请只回复连接成功”。先测试无重要草稿、无危险执行任务的普通聊天。测试会真的出现在你的桌面聊天里。

0.4.1 问答、弹窗与附件修复

0.4.1 本次修复与使用方法（2026-10-21） - 开启完整访问权限或 Ultra 组合提示时，手机会显示桌面确认弹窗。点“取消”或返回会点击实际桌面取消按钮；不使用 Esc，也不操作弹窗背后的聊天。桌面不提供安全关闭控件时，会明确提示。 - 右侧文件、浏览器和预览面板不再作为主聊天输入框。主输入框临时隐藏时仍保留连接，界面恢复后自动同步；有问答时可直接回答，不需切换聊天恢复。 - 有新问题时，手机自动展开“回答电脑的问题”。选择选项或填写文字，使用桌面提供的上一题、下一题、跳过或发送控件。收起后可点“电脑有问题待回答”重新打开，收起不会跳过。电脑已处理或切题后旧操作会被拒绝。 - 专项修复手机新建聊天后出现问答的情况：临时页面转正式聊天标识后仍同步同一聊天，问答替代输入框时不误报断开。冷重连也能识别问题。 - 已发送图片按对应用户消息显示，不再只读取文字气泡；普通已发送文件显示文件名卡片。图片支持原有大图查看。普通上传附件卡片用于确认发送内容，当前不提供从此卡片重新下载；电脑成果文件仍按原有助手文件链接下载并选择阅读器打开。 - 所有操作继续绑定聊天和控件版本。关闭弹窗不清除未知发送，断线不自动补发，已有电脑草稿不覆盖，保持原签名与配对。 覆盖升级 不要卸载旧版。先在手机安装 Codex-Pocket-0.4.1.apk 并选择“更新”。电脑端须同时更新到 0.4.1：只停止配套连接程序，覆盖新版文件并保留原 data 目录，再运行启动器；不要结束正在执行任务的 Codex。本站新用户完整包包含 APK、Windows 程序、源码及详细教程，不包含私人证书和授权。 真机验收顺序（待执行） 1. 确认仍连接原电脑；在手机新建普通聊天并发送消息，使 Codex 提出一个问题；检查同一标题、选项和文字回答。 2. 测试多题导航、收起再打开、电脑先回答后手机旧卡片失效；在问答期间断网再连接。 3. 手机打开完整访问权限提示，先取消，确认桌面弹窗关闭且任务未停止；再自行测试 Ultra 组合提示。不要为验收自动授予完整访问。 4. 在电脑反复打开和收起右侧文件、浏览器、预览，确认手机仍更新且没有误操作侧面输入框。 5. 从手机分别发送纯图片、纯文件、多附件及文字加附件，确认电脑和手机均可见、图片属于对应消息、没有重复；加载历史后再次检查。 6. 分别使用 Wi-Fi 和移动数据，检查自动重连和未知发送不重发。 已验证和限制 电脑端 28 项自动化测试、安卓 JVM 14 项测试通过；正式 APK、调试 APK 和界面测试 APK 编译成功。APK 保持原签名，版本 0.4.1 / versionCode 6，最低 Android 8.0。当前真实 Codex 26.1013.4894.0 只读检查 connected=true、compatible=true，观察到用户图片归于对应消息。上述真实桌面检查不等于已完成全部手机操作。 当前无已授权 ADB 设备，模拟器未运行；手机触屏、系统阅读器、真实新建聊天作答、Ultra 组合设置、Wi-Fi/移动数据切换和长连接仍待用户验证。已恢复工具链和构建缓存，按用户要求保留在私人开发目录，不包含在分享包中。
