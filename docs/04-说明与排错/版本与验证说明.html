版本、验证与适用范围

版本：Codex Pocket 0.3.1，Android versionCode 4，协议版本 3；整理日期 2026-10-20。

最低安卓 8.0 / API 26；target API 35；应用 ID cn.codexpocket.app。

电脑包随附 Windows x64 Node 运行环境；面向 Windows 10/11 x64。ARM64、macOS、Linux、iOS 不在本包验证范围。

已联调桌面版本：Codex 26.1013.4894.0，OpenAI.Codex Windows 应用包。不是官方远程客户端，不保证所有新旧桌面版本兼容。

已完成：

  • 电脑端 16 项自动化测试；Android JVM 9 项测试，均通过。
  • 正式 APK、调试 APK 和界面测试 APK 编译；本包只交付用户使用的正式 APK。
  • 当前真实桌面上读取同一聊天、＋/⋯/权限菜单、问答控件、附件和图片、队列菜单及预览。
  • 0.3.1 真实桌面＋/⋯/权限菜单关闭约 0.2～0.4 秒；三轮＋打开/复用/关闭保持同一聊天和已有草稿。
  • 回归覆盖相同文字的不同消息、流式替换、虚拟历史、嵌套队列去重、草稿保护、旧状态拒绝、防重复、鉴权/撤销/证书。

尚未完整验收：

  • 模拟器因缺少可用加速支持未运行成功；Compose 界面测试只编译，未实际执行。
  • 全套功能的安卓真机验收、Wi-Fi/移动数据切换、长连接、休眠/恢复及双端并发需接收者按检查表测试。
  • 真实引导、队列编辑/关闭排队、系统审批、计划任务创建运行和所有技能的后续行为未逐个完成端到端验收。

0.3.1 修复：

  • 关闭手机＋菜单后电脑菜单不退出、手机操作无响应：使用已展开真实入口关闭，手机本地立即收起，关闭回执与发送等待分离。
  • 不用 Esc 清理菜单，避免它在无菜单时成为停止快捷键；停止需二次确认。
  • 允许把桌面队列“编辑消息”产生的自有草稿移到手机编辑；已有手机/电脑草稿不覆盖。

范围：单电脑、单手机、本地聊天。侧栏只搜索已同步聊天；文件夹需展开选文件。文件和绘图上传后仍需明确加入并发送。

不含完整远程桌面、任意终端、文件编辑、语音、后台推送或 Codex/Work 切换。

分享包只带新用户需要的最新版，不混入旧 APK、旧 Windows 包、历史运行数据、当前聊天内容或发送者的设备身份。
