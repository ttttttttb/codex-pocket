# Codex Pocket 0.4.1 验证说明

## 0.4.1 本次修复与使用方法（2026-10-21）

- 开启完整访问权限或 Ultra 组合提示时，手机会显示桌面确认弹窗。点“取消”或返回会点击实际桌面取消按钮；不使用 Esc，也不操作弹窗背后的聊天。桌面不提供安全关闭控件时，会明确提示。
- 右侧文件、浏览器和预览面板不再作为主聊天输入框。主输入框临时隐藏时仍保留连接，界面恢复后自动同步；有问答时可直接回答，不需切换聊天恢复。
- 有新问题时，手机自动展开“回答电脑的问题”。选择选项或填写文字，使用桌面提供的上一题、下一题、跳过或发送控件。收起后可点“电脑有问题待回答”重新打开，收起不会跳过。电脑已处理或切题后旧操作会被拒绝。
- 专项修复手机新建聊天后出现问答的情况：临时页面转正式聊天标识后仍同步同一聊天，问答替代输入框时不误报断开。冷重连也能识别问题。
- 已发送图片按对应用户消息显示，不再只读取文字气泡；普通已发送文件显示文件名卡片。图片支持原有大图查看。普通上传附件卡片用于确认发送内容，当前不提供从此卡片重新下载；电脑成果文件仍按原有助手文件链接下载并选择阅读器打开。
- 所有操作继续绑定聊天和控件版本。关闭弹窗不清除未知发送，断线不自动补发，已有电脑草稿不覆盖，保持原签名与配对。

### 覆盖升级

不要卸载旧版。先在手机安装 Codex-Pocket-0.4.1.apk 并选择“更新”。电脑端须同时更新到 0.4.1：只停止配套连接程序，覆盖新版文件并保留原 data 目录，再运行启动器；不要结束正在执行任务的 Codex。本站新用户完整包包含 APK、Windows 程序、源码及详细教程，不包含私人证书和授权。

### 真机验收顺序（待执行）

1. 确认仍连接原电脑；在手机新建普通聊天并发送消息，使 Codex 提出一个问题；检查同一标题、选项和文字回答。

4. 在电脑反复打开和收起右侧文件、浏览器、预览，确认手机仍更新且没有误操作侧面输入框。
5. 从手机分别发送纯图片、纯文件、多附件及文字加附件，确认电脑和手机均可见、图片属于对应消息、没有重复；加载历史后再次检查。
6. 分别使用 Wi-Fi 和移动数据，检查自动重连和未知发送不重发。
