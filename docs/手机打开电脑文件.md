# 手机打开电脑生成的文件（0.4.0）

## 先更新两端

1. 电脑等待当前连接操作完成，双击“停止连接程序.cmd”。这只停止 Pocket 配套程序，不结束 Codex。
2. 用新版 Windows 配套程序替换旧程序文件，保留原来的 `data` 文件夹，不能用别人的数据目录覆盖它。
3. 手机下载并**覆盖安装** 0.4.0 APK，选择“更新”；不要先卸载，以免丢失配对和草稿。
4. 电脑运行“启动 Codex Pocket.cmd”，手机和电脑都连接同一 Tailscale 私有网络。
5. 若提示尚未连接 Codex，等 Codex 当前任务结束后正常退出，再通过配套启动器打开。手机沿用原配对。

## 查看与打开

1. 在同一聊天中让 Codex 生成文件，例如“生成一份测试 PDF，并在回复中给出文件链接”。
2. 等文件写完，电脑回复中出现文件链接。手机同步后，会在对应助手回复下显示**文件卡片**，包含文件名、大小和打开按钮。
3. 点击“下载并选择应用打开”，等进度达到 100%。下载会核对大小与 SHA-256，成功后弹出安卓系统的**选择应用打开**窗口。
4. 从列表选择已经安装的应用，例如用 WPS/Microsoft 365 打开 Word、Excel、PPT，用 PDF 阅读器打开 PDF，或用支持对应格式的应用查看图片、文本等。
5. 应用列表由安卓系统根据文件类型和已安装应用决定。没有合适的应用时，Pocket 会提示先安装阅读器；安装后回到聊天，再点击文件卡片。

不会每生成一个文件就自动弹窗。只有你主动点击卡片并完成下载，才调起选择器。打开的是手机上的文件副本；手机阅读器中的编辑不会自动写回电脑文件。

## 下载与存储规则

- 单文件最多 **100 MB**，空文件可下载；既有附件上传仍是每个文件最多 20 MB。
- 文件夹不能直接打开，请让 Codex 提供其中的文件，或先打包成不超过 100 MB 的 ZIP，再使用手机解压工具。
- 支持聊天里实际出现的 Windows 绝对文件链接，以及桌面使用的文件标签。只有路径文字、没有文件链接的回复可能不产生卡片，请让 Codex 提供可点击的文件链接。
- 更早的文件先用“加载历史”读取对应消息。未加载的桌面历史、远程主机文件和网页下载链接不作为本地生成文件下载。
- 下载中的取消按钮只取消文件传输，不停止 Codex 任务。断网或下载失败后不会自动重试；恢复 Tailscale 后主动点击卡片即可。
- 文件被移动、删除、改写或超过大小限制时会提示原因。刷新或重新加载聊天后，再使用最新卡片；不要在电脑还在写文件时下载。
- 下载副本存入应用私有缓存，后续下载时按 24 小时和 250 MB 总量清理，也可能被安卓系统提前回收。需要长期保留时，在阅读器中选择“另存为”或保存到手机文件夹。
- Pocket 不要求“管理所有文件”权限。通过 FileProvider 临时允许你选择的应用读取对应文件；解除配对会清除 Pocket 下载缓存，阅读器自行另存的副本由你管理。

## 简单验收

分别生成 PDF、DOCX、XLSX 或 PPTX 文件，点击手机卡片检查文件名、大小、选择器和内容。再检查无阅读器、超过 100 MB、文件删除、下载中取消、Wi-Fi/移动数据切换及断网重试。

电脑端已增加识别与下载自动化测试。**安卓真机的系统选择器、第三方阅读器、移动网络，以及本次新增文件功能在当前真实 Codex 上的端到端验收仍需实际执行；构建通过不等于这些场景已通过。**
