先了解你将安装什么

Codex Pocket 把你自己的 Windows 电脑上正在打开的 Codex 聊天同步到安卓手机。手机能发指令、看回复、切换聊天并使用桌面提供的常用菜单；操作仍发生在同一段桌面聊天。

安卓手机
Codex Pocket ＋ Tailscale↔你的私有网络
HTTPS / WebSocket↔Windows 电脑
配套程序 ＋ 桌面 Codex

这是非官方个人工具，不是 OpenAI 官方远程功能。本包为 0.4.1，整理于 2026-10-20。发送者的电脑、账号、聊天、二维码和配对数据都不应作为你的默认设置。

本教程可离线阅读。安装 Codex、Tailscale 和首次登录仍需联网。普通使用者不必编译源码，也不必安装 Node.js、Java 或 Android SDK。

02 / 16

第一步：检查设备与账号

项目准备内容
电脑Windows 10/11 x64，可安装官方 Codex 桌面和 Tailscale。已测试桌面版本 26.1013.4894.0，其他版本先做兼容测试。
手机安卓 8.0 或更高；可安装 APK、连接 Tailscale。扫码需相机授权，也可手动粘贴配对内容。
账号能正常使用 Codex 的你自己的账号；一个供你手机和电脑登录的 Tailscale 账号。没有额外 API Key 要求，不代表桌面 Codex 无需账号权限。
使用环境电脑唤醒、联网、已登录且未锁屏，Codex 保持运行；手机 Wi-Fi 或移动数据均可，但必须连接 Tailscale。

本包不支持 iPhone、完整远程桌面或多手机同时配对。不要把“接收了安装包”理解为“可以控制发送者的电脑”。每个人都应在自己的电脑完成下列操作。

03 / 16

第二步：解压并认清文件

  1. 在电脑上把收到的 ZIP 完整解压，不要在压缩包预览窗口里直接运行启动器。
  2. 双击本文件 00-完整安装与使用教程.html 用浏览器阅读。
  3. 01-安卓安装包：手机要安装的 APK。
  4. 02-Windows电脑端：完整电脑程序，包括 runtime、dist、assets、node_modules、windows 等目录。不能只拷贝一个 .cmd 文件。
  5. 03-源码与开发资料：完整源码 ZIP、构建说明及需求记录；普通用户不用打开。
  6. 04-说明与排错：常见问题、验收清单、版本验证边界和官方下载入口。

可选校验：在电脑 PowerShell 中对文件执行 Get-FileHash -Algorithm SHA256 -LiteralPath '文件完整路径'，与根目录 SHA256SUMS.txt 对应行比较。校验用于确认传输完整，不替代对发送来源的判断。

04 / 16

第三步：电脑安装并登录桌面 Codex

  1. 在电脑打开 OpenAI Codex 官方页面，从官方 Windows 下载入口安装桌面应用。下载页面可能随官方调整，以其当前入口为准。
  2. 打开 Codex，登录你自己的账号，完成官方要求的登录/授权。
  3. 先在桌面创建或打开普通本地聊天，发一条简单指令，确认 Codex 本身能正常回复。
  4. 若 Codex 登录或使用权限尚不可用，先解决官方应用的问题，再配置 Pocket。

当前启动器通过 Windows 的 OpenAI.Codex 应用包定位安装位置，其他非标准/便携安装方式不保证自动识别。不要复制别人的 Codex 安装文件或账号会话。安装失败时按官方说明处理。

05 / 16

第四步：两端安装并连接 Tailscale

  1. 电脑打开 Tailscale 官方下载页，选择 Windows，下载安装。
  2. 打开 Tailscale，按其界面登录你自己的账号；若要求授权添加设备，确认是你自己的电脑。
  3. 安卓手机也从该官方下载页选择 Android；可通过其提供的 Google Play 等渠道安装。
  4. 手机登录同一个你自己的 Tailscale 账号/私有网络，开启连接；安卓询问是否允许建立 VPN 时，核对应用是 Tailscale 后允许。
  5. 在 Tailscale 设备列表确认电脑和手机都在线。设备通常获得 100.x.x.x 的私有网络地址，不要照抄别人电脑的地址。
两台设备不必在同一 Wi-Fi；手机在外面用移动数据时仍需连接 Tailscale。Android 通常只允许一个 VPN 同时工作，其他 VPN/代理可能与它冲突。根据手机系统设置，允许 Tailscale 使用移动数据和必要的后台网络权限；屏幕关闭时的行为仍需自己测试。

无需修改路由器，不用公网端口转发，也不要把 Codex 调试端口开放到互联网。若 Tailscale 登录/网络受环境限制，先按其官方排错说明解决。

06 / 16

第五步：在电脑放好程序并首次启动

  1. 把整个 02-Windows电脑端 复制到你电脑的固定位置，例如 D:\CodexPocket；没有 D 盘可选自己的用户目录。避免仍在压缩包、只读目录、系统安装目录或临时下载预览目录中运行。
  2. 等待正在执行的 Codex 任务结束。自行发送、保存或处理输入框草稿，再通过应用正常退出 Codex。不要强制结束正在执行的任务。
  3. 在固定目录双击 启动 Codex Pocket.cmd。启动器会定位官方 Codex、使用只监听本机的调试入口启动它，并在后台启动配套程序。
  4. 程序会自动打开浏览器本机设置页，地址形式是 http://127.0.0.1:43828/。必须通过启动器打开；直接手输不含本机授权的地址不能操作管理功能。
  5. 检查左边显示“准备就绪”，右边显示“已连接”及你正在打开的聊天标题。若未连接，先看下方排错，不要急着重复配对。

第一次运行会在你自己的安装目录生成 data，保存你自己的证书、手机授权等。这个分享包本身不带运行数据。正常情况下无需以管理员身份运行，也不用额外装 Node。

如果出现“未找到 Codex”，先确认已安装并登录官方 Windows 应用。若 Codex 已经从普通快捷方式运行，启动器不会强杀它；等任务结束后正常退出，再从配套启动器重开。

Windows 如果阻止未知发布者应用/脚本，请先核对文件来源和哈希，再按本机提示处理；不要整体关闭系统安全功能。若防火墙询问 runtime/node.exe 的联网权限，仅按自己的受信网络需要允许。

07 / 16

第六步：安卓安装 APK

  1. 将 01-安卓安装包/Codex-Pocket-0.4.1.apk 发到自己的安卓手机。可用 USB、已有文件传输工具，或两端 Tailscale 在线后的文件发送功能。电脑程序目录不需要传到手机。
  2. 在手机“文件/下载”中找到 APK 并打开。某些聊天工具会改变扩展名或阻止直接安装，应先保存原始 .apk 文件。
  3. 系统若提示“禁止安装未知应用”，只给当前打开 APK 的文件管理器或下载工具临时授予“允许此来源安装应用”。不同品牌入口常在“设置 → 安全/隐私 → 特殊应用权限 → 安装未知应用”。
  4. 核对名称为 Codex Pocket，完成安装后打开。可以再关闭该来源的安装权限。
  5. 如果系统提示不兼容，确认安卓至少 8.0；如果说解析失败，重新传输完整 APK 并核对哈希。

这是直接安装 APK，不通过应用商店自动更新。以后升级同签名新版时选择“更新”，不要先卸载；卸载会清除手机端配对和草稿。

08 / 16

第七步：扫码连接你自己的电脑

  1. 保持电脑和手机 Tailscale 都已连接，电脑设置页显示二维码及正确聊天状态。
  2. 手机打开 Codex Pocket，选择扫码入口；第一次使用允许相机权限，镜头对准电脑上的二维码。
  3. 手机出现“连接这台电脑？”时，核对显示的是你自己的电脑名称，点“确认连接”。
  4. 等待手机状态变为连接正常，聊天标题/消息内容与电脑对应。电脑设置页会显示“手机已配对”。

二维码包含地址、证书指纹及一次性配对码，五分钟有效；过期点电脑的“刷新二维码”再扫。不需要在安卓安装系统证书或手动跳过 HTTPS 校验。

无法扫码时：手机选“无法扫码？粘贴配对内容”，把本机设置页显示的手动配对内容完整、私密地传到自己的手机并粘贴，点“下一步”后核对电脑名称再连接。不要把这段内容发到群聊或写进教程截图。

默认只配对一部手机。若已有手机授权，先在电脑设置页点“撤销手机授权”，再让自己的目标手机扫码。正常日常使用不需要每次扫码。

09 / 16

第八步：完成第一次真实收发

  1. 在电脑打开一个普通本地聊天，确保没有未发送草稿、重要执行任务或尚未处理的确认框；只保留一个 Codex 聊天窗口。
  2. 对照手机标题和电脑标题，确认同一聊天。
  3. 在手机发一条唯一文字，例如 连接测试-自选编号：请只回复连接成功。
  4. 检查电脑同一聊天出现这条用户消息，手机上也只出现一条；助手回复随电脑逐步更新。不要连点发送。
  5. 在电脑再发另一条测试文字，确认手机收到。桌面切换聊天时手机应跟随；手机侧栏切换也应让桌面打开对应聊天。
  6. 手机点“＋”后在手机关闭菜单，确认电脑菜单也退出；连续三次后仍能打开“⋯”或继续操作。
  7. 逐项完成 首次安装验收清单。网页版可直接阅读，也附有可编辑的 Markdown 清单。

电脑的 检查同一聊天连接.cmd 默认只读检查；它询问时直接回车退出，输入大写 TEST 才会在当前空闲、无草稿聊天真实发送测试消息。它不是假数据预览。

“已配对”只说明身份授权完成，不代表已连上 Codex。必须同时确认桌面状态、同一聊天和真实收发。其他设备或新桌面版本首次使用时也要做这一步。
10 / 16

日常使用：以后每次怎样打开与关闭

  1. 电脑联网并登录，连接 Tailscale；从固定目录的启动 Codex Pocket.cmd打开。
  2. 手机连接 Tailscale，打开 Codex Pocket，等待同步已有配对。
  3. 电脑保持唤醒、联网、登录且未锁屏，Codex 不退出。外出前可在系统电源设置按需延长接电休眠时间；屏幕熄灭与电脑休眠/锁屏不是同一件事。
  4. 手机断网后会尝试重连并重新读取状态，不自动补发指令。遇到“操作结果待确认”先看原指令是否已经执行，确认后点“我已检查聊天”，再决定是否手动重发。
  5. 结束手机访问可关闭 App/断开 Tailscale；关闭 App 不等于撤销电脑授权，也不自动停止电脑任务。停止配套服务用停止连接程序.cmd，它不会结束 Codex 任务。

不要在任务进行中为了重连而退出 Codex。关闭浏览器设置页本身不停止后台配套程序；启动器可再次打开管理页。

常用功能逐项使用

聊天列表、新建与草稿

点左上聊天列表查看项目分组、最近聊天和当前聊天标记；搜索范围是已同步聊天，不是整个账号的全部历史。新建聊天可选择已有项目或普通本地聊天，先在电脑打开新聊天输入页，首条消息后关联实际聊天。手机按聊天保存草稿；电脑存在未发送草稿时会阻止会覆盖它的发送、新建、切换或附件操作，请先处理电脑草稿。

＋菜单、计划/目标与模型

左下“＋”从桌面读取实际选项，包括文件、目标、计划模式及已配置工具/技能。不要把“计划模式”当成整个＋菜单的替代。点当前模式标签可按桌面能力退出；目标模式发送前会确认是否设为目标。权限、模型、思考强度使用当前桌面可用选项；选中状态以桌面确认结果为准，控件变动时旧操作会被拒绝。

聊天⋯与条目自己的⋯

右上“⋯”是当前聊天的重命名、置顶、分叉、复制、归档等菜单，以桌面实际提供为准；窗口/侧边面板专属项不显示。归档等操作需要确认。计划任务需核对完整表单、时间和重复规则后提交，仅打开菜单不表示已创建。复制结果在确认桌面剪贴板变化后传到手机；连续复制同样内容可能显示待确认。

执行中的排队、引导与停止

发送方式跟随桌面当前控件，不能笼统说手机每次都是引导。消息进入实际队列后，输入框上方出现消息条，带摘要、预览、引导、删除和该条自己的“⋯”。点引导才操作这条消息的桌面引导按钮；删除只取消对应待处理条目。若菜单提供“编辑消息”，选后可“移到手机输入框编辑”，已有草稿会阻止覆盖。停止任务必须二次确认。

回答 Codex 的选择题

聊天中的问答卡片会显示真实问题及选项，可以选择或填自定义答案；多题按桌面导航逐题处理，仅桌面支持多选时才提供多选。提交的是原问题控件，而不是再发一条普通消息。桌面已回答、问题变化或切换聊天时不要继续提交旧卡片。

从手机/电脑选文件与画图

  1. “＋ → 文件和文件夹”，选择“从手机选择”进入安卓系统选择器，或“从电脑选择”浏览电脑目录再选文件。文件夹目前需展开后选文件。
  2. 单文件 1 字节～20 MB；待添加缓存共 64 MB、30 分钟过期。先预览，再点加入聊天。
  3. 确认附件出现在当前聊天输入区，最后手动发送；选择文件不会自动发消息。
  4. 绘图打开手机画板，支持撤销/清空/取消，完成后预览 PNG，再加入聊天并发送。取消不发送。

图片、历史和外观

聊天、附件与队列图片可点缩略图看大图，支持双指缩放/拖动，失败可重试；旧图片依赖桌面已加载历史。向上阅读时不会强制滚到底部，可用回到底部按钮。侧栏“连接与外观”可重连、选择跟随系统/浅色/深色，以及解除配对。

连不上时按这个顺序查

  1. 电脑是否唤醒、联网、登录且未锁屏？Codex 是否运行？两端 Tailscale 是否连接到同一私有网络？
  2. 重新运行配套启动器打开本机设置页，分别查看网络/配对状态和电脑 Codex 状态，点“重新检测”。
  3. 若“已配对，尚未连接 Codex”，等当前任务结束、处理草稿，正常退出 Codex 后从配套启动器打开。不要只重装手机 App。
  4. 手机“连接与外观”中手动重连。二维码过期则刷新；证书不匹配则核对电脑，不跳过校验。
  5. 只保留一个 Codex 聊天窗口。桌面升级后，重启配套程序并再运行同一聊天连接检查；控件不兼容时停止相关功能。
  6. 需要时运行“修复电脑端连接.cmd”，它只重启配套服务；不替代任务结束后重新启动 Codex。

完整症状表见 常见问题。错误日志在你自己的安装目录 data/startup-error.log。反馈时仅发经过检查的错误片段、设备/版本/时间和操作步骤，不发整个 data、二维码、完整管理页地址或聊天正文。

手机网络被策略限制时，确认允许它通过 Tailscale 访问电脑的 TCP 43827。不关闭整个防火墙，不做公网映射。9222 是电脑本机调试入口，43828 是本机管理页，均不应对手机或公网开放。

升级、换手机与卸载

收到后续新版

  1. 保存草稿并确认未决操作结果；先停止配套程序，不必停止 Codex 当前任务。
  2. 备份自己电脑程序中的 data 到自己的私密位置。将新版电脑程序覆盖到固定目录，保留原 data；运行新版启动器。
  3. 手机打开同签名、较高版本号的新版 APK，选“更新”。不要先卸载，不要用自行重签名的包替代正式更新。
  4. 确认仍连接原电脑，并复测消息、菜单和草稿。

更换手机/解除授权

  1. 在电脑本机设置页点“撤销手机授权”，旧手机即不能继续控制。
  2. 旧手机在“连接与外观”解除配对；此操作会清除该手机的配对和草稿。
  3. 新手机安装 App、连接同一 Tailscale 网络，再扫描新二维码。

不再使用

先撤销手机授权、停止配套程序，再按需卸载手机 App，删除你自己的电脑程序目录。删除 data 会失去配对证书、操作回执及暂存附件；确认没有聊天继续引用附件后再清理。Pocket 不会替你卸载官方 Codex/Tailscale，也不会自动删除 Codex 聊天。

分享前与使用中的数据说明

本包来自干净发布目录，首次运行才产生个人身份。不要在自己的电脑配对使用后，直接把整个运行目录再发给别人。后续分享应重新使用这个未运行的原始分享 ZIP。

内容处理方式
data/tls.json、device.json、dashboard.url证书私钥、授权校验资料、本机管理入口，仅留自己电脑；不随分享包分发。
二维码/手动配对内容一次性短时凭据，仅给自己的手机。
安卓 Keystore/签名私钥源码包不带发布私钥；原 APK 已签名可安装，复编需自己配置签名。
data/attachments电脑为让 Codex 后续读取而保存的上传副本；发出/移除附件后不会立即删盘上副本，聊天不再引用时再自行清理。
文件上传与图片需要已配对凭据；手机图片内存缓存最多 32 MB，电脑图片缓存最多 64 MB。

限制接口只允许已实现的聊天操作，手机不能发送任意系统命令、脚本、选择器或 CDP 方法。私有网络不替代你对操作内容的判断；手机的完全访问/审批会作用于电脑真实任务。

手机打开电脑生成的文件

先更新两端

1. 电脑等待当前连接操作完成，双击“停止连接程序.cmd”。这只停止 Pocket 配套程序，不结束 Codex。 2. 用新版 Windows 配套程序替换旧程序文件，保留原来的 data 文件夹，不能用别人的数据目录覆盖它。 3. 手机下载并覆盖安装 0.4.1 APK，选择“更新”；不要先卸载，以免丢失配对和草稿。 4. 电脑运行“启动 Codex Pocket.cmd”，手机和电脑都连接同一 Tailscale 私有网络。 5. 若提示尚未连接 Codex，等 Codex 当前任务结束后正常退出，再通过配套启动器打开。手机沿用原配对。

查看与打开

1. 在同一聊天中让 Codex 生成文件，例如“生成一份测试 PDF，并在回复中给出文件链接”。 2. 等文件写完，电脑回复中出现文件链接。手机同步后，会在对应助手回复下显示文件卡片，包含文件名、大小和打开按钮。 3. 点击“下载并选择应用打开”，等进度达到 100%。下载会核对大小与 SHA-256，成功后弹出安卓系统的选择应用打开窗口。 4. 从列表选择已经安装的应用，例如用 WPS/Microsoft 365 打开 Word、Excel、PPT，用 PDF 阅读器打开 PDF，或用支持对应格式的应用查看图片、文本等。 5. 应用列表由安卓系统根据文件类型和已安装应用决定。没有合适的应用时，Pocket 会提示先安装阅读器；安装后回到聊天，再点击文件卡片。

不会每生成一个文件就自动弹窗。只有你主动点击卡片并完成下载，才调起选择器。打开的是手机上的文件副本；手机阅读器中的编辑不会自动写回电脑文件。

下载与存储规则

- 单文件最多 100 MB，空文件可下载；既有附件上传仍是每个文件最多 20 MB。 - 文件夹不能直接打开，请让 Codex 提供其中的文件，或先打包成不超过 100 MB 的 ZIP，再使用手机解压工具。 - 支持聊天里实际出现的 Windows 绝对文件链接，以及桌面使用的文件标签。只有路径文字、没有文件链接的回复可能不产生卡片，请让 Codex 提供可点击的文件链接。 - 更早的文件先用“加载历史”读取对应消息。未加载的桌面历史、远程主机文件和网页下载链接不作为本地生成文件下载。 - 下载中的取消按钮只取消文件传输，不停止 Codex 任务。断网或下载失败后不会自动重试；恢复 Tailscale 后主动点击卡片即可。 - 文件被移动、删除、改写或超过大小限制时会提示原因。刷新或重新加载聊天后，再使用最新卡片；不要在电脑还在写文件时下载。 - 下载副本存入应用私有缓存，后续下载时按 24 小时和 250 MB 总量清理，也可能被安卓系统提前回收。需要长期保留时，在阅读器中选择“另存为”或保存到手机文件夹。 - Pocket 不要求“管理所有文件”权限。通过 FileProvider 临时允许你选择的应用读取对应文件；解除配对会清除 Pocket 下载缓存，阅读器自行另存的副本由你管理。

简单验收

分别生成 PDF、DOCX、XLSX 或 PPTX 文件，点击手机卡片检查文件名、大小、选择器和内容。再检查无阅读器、超过 100 MB、文件删除、下载中取消、Wi-Fi/移动数据切换及断网重试。

电脑端已增加识别与下载自动化测试。安卓真机的系统选择器、第三方阅读器、移动网络，以及本次新增文件功能在当前真实 Codex 上的端到端验收仍需实际执行；构建通过不等于这些场景已通过。
