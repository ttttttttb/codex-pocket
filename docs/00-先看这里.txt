Codex Pocket 0.4.3 新用户完整安装包
整理日期：2026-10-21

请先双击同目录的「00-完整安装与使用教程.html」，普通浏览器可离线阅读。
本包用于连接你自己的 Windows 电脑与自己的安卓手机，不连接发送者的电脑。

你需要：Windows 10/11 x64、安卓 8.0 或更高版本、可使用 Codex 的账号、联网。
已验证的桌面 Codex 版本：26.1013.4894.0。其他版本请先做兼容性与同一聊天测试。
手机 App 为非官方个人工具；无需额外 API Key，但桌面 Codex 本身需要账号和可用权限。

六步开始：
1. 电脑先从 https://openai.com/codex/ 找到官方 Windows 下载入口，安装并登录 Codex，确认本身可以聊天。
2. 电脑和手机从 https://tailscale.com/download 安装 Tailscale，登录同一个你自己的账号，两端都连接。
3. 电脑将「02-Windows电脑端」整个文件夹复制到固定位置，例如 D:\CodexPocket；不要只复制启动器。
4. 等当前 Codex 任务结束，保存/处理草稿并正常退出 Codex，再在该目录双击「启动 Codex Pocket.cmd」。
5. 手机安装「01-安卓安装包」中的 APK，打开 Codex Pocket，扫码电脑本机设置页的二维码并确认连接。
6. 确认两端聊天标题一致，手机发送“连接测试：请只回复连接成功”，检查两端只出现一次，再测电脑发送。

以后：电脑登录 Tailscale → 用配套启动器打开 → 手机连接 Tailscale → 打开 Codex Pocket。
电脑需保持联网、唤醒、登录且未锁屏。配对成功后不必每次扫码。

重要：安装依赖需联网；本包不含 Codex/Tailscale 官方安装器、账号、订阅、Android SDK/JDK。
运行电脑程序不需要另外装 Node、JDK 或 Android SDK。不要把运行后生成的 data 分享出去。
收到本分享包不等于所有设备已兼容；先完成教程中的收发/菜单/草稿测试。真机网络切换等仍需接收者验收。
